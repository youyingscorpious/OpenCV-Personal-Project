## 4. `_on_enter()` —— 进入路口

**位置**：`route_controller.py` 的 `_on_enter`，`if state == 'WAIT_ROUTE_MANEUVER':` 分支。

**改前**

```python
        if state == 'WAIT_ROUTE_MANEUVER':
            self._junction_enter_ts = time.monotonic()
            self._turn_phase = 'idle'
            if not self._maneuver_done_once:

            self._publish_comp('JUNCTION_PARKED', 'stopped at junction; waiting for route color')
```

**改后**

```python
        if state == 'WAIT_ROUTE_MANEUVER':
            self._junction_enter_ts = time.monotonic()
            self._turn_phase = 'idle'
            if not self._maneuver_done_once:
                self._route_done = False
                # I2：丢掉行进途中被误锁的颜色，本轮只认停稳之后的识别结果

            self._gate_on_junction_enter()
            self._publish_comp('JUNCTION_PARKED',
```

> ⚠️ `self.selected_route = None` 必须写在 `if not self._maneuver_done_once:` 里。
> 转向完成后被固件锁存的路口事件打回路口时，清空 `selected_route` 会导致二次转向。

## 6. `_select_route()` —— 整段替换

原实现的 253–291 行全部替换为：

```python
    def _select_route(self, color):
        """重写原实现：颜色只在「停稳后的识别窗口」里投票锁定（规则 4.2）。"""
        if not self._enh_ready or not self.route_turn_enabled:
            return super()._select_route(color)
        if color not in (1, 2, 3):
            return
        if self.state == 'ROUTE_FOLLOW' or self._route_done or self._turn_phase != 'idle':
            return
        # I3：已锁定颜色，后续帧一律忽略
        if self.selected_route in (1, 2, 3):
            return

        now = time.monotonic()
        # I2：停稳之前的颜色帧不记录、不投票（行进中 / 路口未确认 / 已锁定）
        if not self._gate_allows_color(color, now):
            return
        # 去抖：连续 N 帧同色才锁定
        if not self._gate_vote(color, now):
            return

        self.selected_route = color
        self._route_pub_cache = color
        route_msg = UInt8()
        route_msg.data = color
        self.route_pub.publish(route_msg)

        if self.state == 'WAIT_ROUTE_MANEUVER':
            self._publish_comp(
                'ROUTE_COLOR_READY',
                'color=%d confirmed by %d frames at junction' % (color, self._vote_count),
            )
        elif self.state == 'LINE_FOLLOW' and self.turn_on_color_without_junction:
            # D7 应急路径：没有路口事件也停车转向，颜色投票仍然生效
            self._publish_comp(
                'ROUTE_COLOR_READY',
                'color=%d seen without junction event (fallback)' % color,
            )
            self._dispatch('JUNCTION_DETECTED',
                           'route color seen; stopping to maneuver')
        else:
            self.get_logger().info(
                'route color=%d (%s) recorded; maneuver waits for junction stop'
                % (color, ROUTE_NAME.get(color, '?'))
            )
```

**删掉的旧逻辑**（不要保留，会和闸门冲突）：

```python
        # 旧：同色重复帧去重（被 selected_route 早退取代）
        if self.selected_route == color and self._route_pub_cache == color:
            return
```

## 7. `_competition_tick()` —— 驱动闸门

**改前**

```python
        if self.state == 'WAIT_ROUTE_MANEUVER':
            self._junction_tick(now)
```

**改后**

```python
        if self.state == 'WAIT_ROUTE_MANEUVER':
            self._gate_tick(now)          # ← 先推进停稳确认（G1 → G2）
            self._junction_tick(now)
```

> 顺序重要：同一个 tick 内先确认停稳，再判断能否转向，避免多等 20 ms。

## 11. `config/competition.yaml` 新增参数

**位置**：`robopioneers_navigation: ros__parameters:` 区块，`refresh_zero_in_wait_stop` 之后。

```yaml
    # ---------------- 本方案新增：路口「停车 → 色卡识别」闸门 ----------------
    # 总开关；false = 完全回到本方案落地前的行为（行进中锁存、到路口就转）。
    junction_gate_enabled: true
    # 停稳确认：连续多少帧 0x10 满足「状态=停 + 左右轮速≈0」。
    junction_stop_confirm_samples: 3
    # 停稳确认：从首帧满足起，至少持续多久（秒）。
    junction_stop_confirm_dwell_s: 0.25
    # 停稳确认：多久还没确认就放弃等待（秒）。
    junction_stop_confirm_timeout_s: 2.0
    # 放弃等待后的动作：proceed（告警后强制开窗）/ fault（进 FAULT）。
    junction_stop_confirm_timeout_action: proceed
    # 只采信「停稳之后」的颜色帧。
    route_color_require_after_stop: true
    # 锁定所需连续同色帧数；1 = 来一帧就锁（原行为）。
    route_color_vote_frames: 3
    # 投票有效期（秒）：超过这么久没有同色帧就重新计数。
    route_color_vote_timeout_s: 0.6
    # 「丢弃颜色帧」告警限频（Hz）。
    route_color_reject_log_hz: 2.0
```

> 注意 YAML 的 key 必须是 `robopioneers_navigation:`（节点名继承自原节点，未改），
> 写错成 `robopioneers_competition` 参数不会生效——这是原包既有的坑。
